# 💬 Messenger PRO

Личный мессенджер для общения с друзьями в реальном времени.  
Свои аккаунты, личные сообщения, статусы онлайн, тёмная тема и загрузка файлов — всё работает из коробки.

---

## ✨ ВОЗМОЖНОСТИ

- ✅ **Регистрация и вход** — у каждого свой аккаунт, пароли хэшируются
- ✅ **Личные сообщения** — приватные чаты 1 на 1
- ✅ **Статусы онлайн/оффлайн** — зелёные точки показывают, кто в сети
- ✅ **Непрочитанные сообщения** — красные счетчики на чатах
- ✅ **Поиск пользователей** — быстрый поиск по имени
- ✅ **Мобильная версия** — адаптивный дизайн, кнопка меню
- ✅ **Мгновенная доставка** — WebSocket, сообщения приходят сразу
- ✅ **История переписки** — сохраняется на сервере
- ✅ **Тёмная тема** — переключатель в сайдбаре (v1.1.0)
- ✅ **Приветственный ASCII-экран** — встречает при запуске (v1.1.1)
- ✅ **Загрузка файлов и изображений** — 📎 отправляй картинки и документы до 20MB (v1.2.0)
