# 💬 Messenger PRO

Мой личный мессенджер для общения с друзьями.

## ✨ Возможности
- ✅ Регистрация и вход
- ✅ Личные сообщения
- ✅ Статусы онлайн/оффлайн
- ✅ История переписки
- ✅ Поиск пользователей

## 🚀 Установка на свой сервер

```bash
git clone git@github.com:ваш-логин/messenger-pro.git
cd messenger-pro
npm install
node server.js

📱 Доступ
Откройте http://ваш-сервер:8080

🔧 Технологии
Node.js

WebSocket (библиотека ws)

bcrypt для паролей

Чистый HTML/CSS/JS
